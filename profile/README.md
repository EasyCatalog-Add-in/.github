## 🚀 Introduction
The plugin EasyCatalog, developed by 65bit Software, reimagines how data-heavy documents are made in Adobe InDesign for Windows. Rather than treating a catalog as a static page you edit by hand, it treats the page as a live presentation of your database. Product fields, prices, codes, and descriptions are pulled from the source you nominate and placed into your design, so a change in the data becomes a change on the page. For studios that publish catalogs, price lists, and directories again and again, this turns a slow, error-prone task into a repeatable production line.

## ✨ Highlights

### Bring your data in
- **Flexible sources** — Connect to databases, spreadsheets, or delimited text files from within Adobe InDesign.
- **Field mapping** — Match each column of your data to a place in the layout once, then reuse it.

### Keep it in sync
- **Synchronized records** — Refresh the document when the source changes so nothing drifts out of date.
- **Consistent styling** — Bind paragraph and character styles to fields for uniform, on-brand output.
- **Automated layout** — Repeat and paginate records across spreads without placing them individually.

## 💻 System Specs
**Minimum**
- OS: Windows 10 64-bit
- Host application: A supported version of Adobe InDesign
- Processor: A modern 64-bit processor
- Memory: The minimum required by your InDesign version
- Storage: Room for the add-in alongside your InDesign installation

**Recommended**
- OS: Windows 11 64-bit
- Host application: The current release of Adobe InDesign
- Processor: A recent multi-core 64-bit processor
- Memory: 16 GB or more for large data sets
- Storage: An SSD with space for source files and documents

## 📥 How to Install
1. Select the **Download** button above to obtain the EasyCatalog add-in package for Windows.
2. Exit Adobe InDesign, then run the installer and follow the setup steps to register the add-in with your host application.
3. Start Adobe InDesign and locate EasyCatalog in the plugin or Window menu, where its panel opens ready to link to your data.

## 🎯 Getting Up and Running
1. Open the InDesign document that will hold your catalog.
2. Reveal the EasyCatalog panel and connect it to your chosen data source.
3. Compose one record by dropping fields onto the page and styling them.
4. Direct the panel to flow and paginate the remaining records.
5. Amend the source data and refresh to bring your layout back into agreement.

## ❓ Common Questions
**Is EasyCatalog free?**
EasyCatalog is a paid add-in from 65bit Software. A trial or demo lets you explore the data-publishing workflow inside Adobe InDesign before committing to a license.

**Which versions of Windows are supported?**
It runs on current 64-bit Windows releases such as Windows 10 and Windows 11, matched to the Adobe InDesign version hosting the add-in.

**Is my data secure?**
The add-in reads only the sources you select, and your documents and data stay on the systems you already use, so control of your information remains with you.
